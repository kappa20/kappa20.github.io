# Révision MLOps & DataOps

Site de révision pour l'examen de MLOps & DataOps (Pr. AIT DAOUD, FSBM, Université
Hassan II, 2025/2026). Couvre les 6 chapitres du cours à partir des supports de cours
et des TD/TP réels.

**En ligne :** https://kappa20.github.io/mlops_dataops_revision/

## Fonctionnalités

- **Flashcards** — cartes à retourner, filtrables par chapitre, suivi "connue / à revoir".
- **Quiz** — QCM avec correction immédiate + questions ouvertes auto-évaluées.
- **Examen** — reprend la structure exacte des TD/TP (QCM, questions directes,
  définitions, questions d'analyse, étude de cas), avec chronomètre et correction
  masquée section par section.
- **Mindmap** — carte mentale 2D par chapitre (déplier/replier, glisser, zoomer, cliquer
  une feuille pour voir sa définition).

Zéro dépendance externe, zéro build — un simple site statique en HTML/CSS/JS.

## Utilisation locale

```
python3 -m http.server 8080
```
puis ouvrir `http://localhost:8080/`.
